# 數位易經 · 三數起卦（完整版）

輸入三個數字起卦，依所問類別直接給出卦象、動爻爻辭與白話解讀。

**線上使用**：https://kftseng2oo1.github.io/gold/

## 主要功能
- 三數起卦：前兩數定上下卦，三數相加定動爻
- 先選問題類別（事業、健康、感情、財運、股市、購物、訴訟、房產等），解讀會依類別不同
- 內建六十四卦全部爻辭，以及每爻在各類別的白話建議

## 使用方式
1. 選擇問題類別
2. 輸入三個數字
3. 按「開始占卜」

## 技術與依賴
- 單檔 HTML PWA（`index.html` 內含全部 HTML/CSS/JS），`manifest.json` + `sw.js` 提供安裝到主畫面與離線快取。
- 純前端、無外部連線、不儲存資料
